# narezki — прототип нарезчика стримов GTA 6

Делает из горизонтального стрима один вертикальный клип 1080×1920 (30–40 с) со звуком.

```bash
./run.sh            # sample.mp4 в корне → режет его; иначе генерирует тестовый исходник
```

Для реального стрима укажите регионы вебки и таймера в координатах исходника:

```bash
CAM=1400:760:500:300 TIMER=20:20:380:80 ./run.sh
```

Что делает `narezchik.py`:
1. FFmpeg-анализ: RMS звука по секундам (`astats`) + динамика картинки (`scdet`).
2. Выбор одного цельного окна 30–40 с с максимальной активностью (+ контекст до/после).
3. Рендер: вебка сверху (1080×608), геймплей снизу (центральный кроп 1080×1312),
   увеличенный таймер поверх геймплея, прожжённые субтитры.
4. Проверка через ffprobe (разрешение, длительность, аудиодорожка) → `output/clip.json`.

Субтитры: `<исходник>.srt` или `--srt`; если установлен `openai-whisper` — расшифровка автоматически.

## Текущий результат
Лёгкая копия для просмотра в браузере: `output/clip_preview.mp4` (~8 МБ).

`output/clip.mp4` собран из **тестового** исходника (`make_test_source.sh`), т.к. `sample.mp4`
в репозитории нет. Выбран момент 00:00:50.000 — 00:01:30.000 исходника (40 с).
Субтитры в тестовом прогоне — заранее заданная SRT-фикстура, не распознавание речи.

## Find Twitch Clips (GitHub Actions)

Workflow `.github/workflows/find-twitch-clips.yml`, ручной запуск (`workflow_dispatch`):
Actions → **Find Twitch Clips** → Run workflow. Нужны секреты `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`.

Скрипт `scripts/find_twitch_clips.py` через Twitch Helix API берёт публичные клипы канала
(по умолчанию `strogo`) за последние 24 ч, фильтрует по категории `Grand Theft Auto VI`
и сортирует от новых к старым. Отчёт — в Summary запуска (название, ссылка, дата, длительность,
просмотры), JSON — артефакт `twitch-clips`. Статусы: `found` / `empty` (успех, 0 клипов) /
`error` (ошибка авторизации или API — job падает).
